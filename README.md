A high-performance, production-grade professional portfolio built for the modern web. This project serves as a showcase of my technical expertise in **Full-Stack Development** and **Cyber Security**, featuring intelligent AI integration and seamless user experience.

---

## ✨ Key Features

- **🌓 Dynamic Dark/Light Mode**: Premium, class-based theme switching with system preference detection and FOUC (Flash of Unstyled Content) prevention.
- **🌐 Full Localization (EN/ID)**: SEO-optimized multi-language support (English and Indonesian) with path-based routing (`/id`).
- **🤖 Hybrid AI Assistant**: Intelligent chatbot integrated with the Google Gemini API, capable of answering 400+ specific questions about my professional background.
- **⚡ Blazing Fast Performance**: 95+ Lighthouse scores achieved through Astro's specialized island architecture and static site generation (SSG).
- **📱 Ultra-Responsive Design**: Tailored experience across mobile, tablet, and desktop using a custom "Sage Green & Steel Blue" aesthetic.
- **🛡️ Security Focused**: Built with secure coding practices, sanitized forms, and modern web protocols (TLS 1.3, JWT logic).

## 🛠️ Tech Stack

### Frontend & Core
- **Framework**: [Astro 5.0](https://astro.build/) (Island Architecture)
- **Styling**: [Tailwind CSS 4.0](https://tailwindcss.com/)
- **Interactivity**: [React](https://react.dev/), [Lucide Icons](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/), [GSAP](https://gsap.com/)

### Backend & Integrations
- **Form Handling**: [Web3Forms](https://web3forms.com/)
- **AI Engine**: [Google Gemini Pro API](https://ai.google.dev/)
- **Analytics**: Vercel Analytics

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0 or higher)
- npm or pnpm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/wi5nuu/wisnu_alfian_nur_ashar.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production
```bash
npm run build
```
